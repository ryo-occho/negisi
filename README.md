# negisi

アプリケーション開発用のリポジトリです。使用する言語やフレームワークは未選定です。

## ディレクトリ構成

| フォルダー | 用途 |
| --- | --- |
| `src/` | アプリケーションのソースコード |
| `tests/` | 自動テスト |
| `docs/` | 設計・仕様・開発手順 |
| `scripts/` | 開発・ビルド・運用の補助スクリプト |
| `config/` | 機密情報を含まない設定ファイル |
| `public/` | 公開する静的ファイル |

## 開発について

技術スタックの決定後、実行・ビルド・テストの手順と必要な依存関係を追加してください。
環境変数に秘密情報を設定し、実際の `.env` ファイルはコミットしないでください。
必要な環境変数の説明は、値を含めず `.env.example` に記載します。
