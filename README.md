# negisi

茨城県つくばみらい市の和食料理店「ねぎしや」で使う、スタッフ向けのシフト調整 Web アプリケーションです。
約12人のスタッフの希望シフトを集め、管理者による調整と確定シフトの共有を行うことを目指します。
アプリの販売や収益化を目的とせず、ねぎしやでの利用を想定しています。

## 現在の状態

開発準備段階です。リポジトリの基本構成と開発ガイドを用意しています。
アプリ本体、データベース、認証、デプロイはまだ実装・設定していません。
以下の機能と技術構成は開発予定です。

## シフトの運用

- スタッフは約12人です。
- シフトは半月ごとに決めます。
- 前半は毎月1〜15日、後半は16日〜月末を対象とする想定です。
- 例として、10月末に11月前半のシフトを決定します。
- 希望の提出期限や勤務時間帯などの詳細は、実際の運用に合わせて決めます。

## 初期開発で予定する機能

- スタッフと管理者のログイン
- スマートフォンからの希望シフトの提出・修正
- 管理者による提出状況と希望シフトの一覧確認
- 管理者によるシフトの調整・確定・公開
- スタッフによる公開済みシフトの確認

希望シフト、調整中のシフト、公開済みシフトを分けて管理し、編集途中の内容を誤って公開しない設計にします。

## 採用予定の技術構成

| 役割 | 技術・サービス |
| --- | --- |
| 画面・サーバー処理 | Next.js / TypeScript |
| スタイリング | Tailwind CSS |
| データベース | Supabase PostgreSQL |
| 認証 | Supabase Auth |
| ホスティング | Vercel |
| ソースコード・PR 管理 | GitHub |

開発は Supabase Free と Vercel Hobby を利用する方針です。
各サービスの利用条件・無料枠を確認しながら進めます。
無料プランでは休止やバックアップなどの制限があるため、実運用に必要な対策は別途検討します。

## ディレクトリ構成

| フォルダー | 用途 |
| --- | --- |
| `src/` | アプリケーションのソースコード |
| `tests/` | 自動テスト |
| `docs/` | 設計・仕様・開発手順 |
| `scripts/` | 開発・ビルド・運用の補助スクリプト |
| `config/` | 機密情報を含まない設定ファイル |
| `public/` | 公開する静的ファイル |

技術スタックの導入に合わせて、必要なフォルダーを追加・調整します。

## 開発環境

依存関係はまだ導入していません。現時点では起動・ビルド・テストのコマンドはありません。
アプリの初期実装時に、必要なバージョンとセットアップ手順を追記します。

認証情報や実際の `.env` ファイルはコミットしないでください。
必要な環境変数は、秘密の値を含めず `.env.example` に記載します。
スタッフの個人情報や実際のシフトデータも公開リポジトリには含めません。
