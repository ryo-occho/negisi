# ローカル用サンプルデータ

せいや、吉田、かいやき、ザイオン、とあ、ゆな、ゆい、落合、るみ、ひろくんの10名と、次の2期間の希望データを用意します。るみ・ひろくんにはシフト作成権限を設定します。

```sh
npm run db:start:app
npm run db:seed
```

メールアドレス・パスワードの登録は不要です。アプリを開き、自分の名前を選んで利用します。ローカルURLは http://127.0.0.1:3100 です。接続用の環境変数は Supabase のローカルURL・公開キーに設定してください。

スクリプトは http://127.0.0.1:55321 以外への投入を拒否します。既存スタッフのIDや既存の希望は維持し、受付終了後は希望を追加しません。利用停止のスタッフは再開させません。名前が重複している場合は勝手に統合せず中止します。

認証・REST API・DBが必要です。以前のメールログイン方式で作成されたローカルスタッフも、同じ名前を再利用します。以前の .env.seed.local は参照・更新しません。

DBだけが起動済みの場合や匿名サインイン設定を変更した場合は、npx supabase stop --project-id negisi でこのプロジェクトだけを停止してから起動します。--no-backup は付けず既存データを保持します。
